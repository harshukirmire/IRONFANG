# PITBULL — Frontend

React app (Create React App + [Craco](https://craco.js.org/) + Tailwind). Main docs, API overview, and environment setup live in the **repository root** [`README.md`](../README.md).

## Quick start

```bash
npm install
npm start
```

Set `REACT_APP_BACKEND_URL` in `.env` (see root README).

## Scripts

| Command       | Purpose        |
|---------------|----------------|
| `npm start`   | Dev server (:3000) |
| `npm run build` | Production bundle |
